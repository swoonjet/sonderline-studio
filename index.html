A production system for Sonderline's social content

A team member writes a brief. Claude chooses approved copy, a layout and a crop. The engine renders every format to the brand grid and checks each one against the brand guide, and named reviewers approve the result. The same rules produce still posts, carousels, slides and short videos.

Trying the prototype
Open the Social Studio and choose "Review example · first draft (v1)" to see the checks block a post that breaks the guide. Then choose v3 to see the corrected version and approve it.

The Studios work in any current browser without a login. Live Claude drafting needs an Anthropic API key, which is pasted into the Studio and kept only in that browser tab. Without a key, an offline drafter is used.

Summary

Why social content

Social is the content type Sonderline produces most. Each message is needed in four or more formats, and most of the production time goes into adapting work between formats.

How it works

Seven steps share one set of brand rules: brief, Claude drafting, layout, automated checks, human review, delivery and rule updates.

Quality control

Thirteen rules from the brand guide are checked on every output. Failures block approval, new copy goes to product marketing, and the designer makes the final craft decisions.

Video

The Video Studio uses the same rules for short video posts. It combines footage generated from the supplied photos with overlays and type animation, all timed to the music.

Presentations

The Deck Studio builds slides from the same rules and checks, with speaker notes, and exports an editable PowerPoint file and a PDF.

Figma brand kit

A brand kit for designers, built in FigCraft from the same rule files. It has colour variables, Inter Tight text styles, the logos, components and templates for every format.

Claude skill

A Claude skill, /sonderline, that makes and checks Sonderline assets with this system and follows the same copy and brand rules.

Status

The engines, checks, the three Studios, the command-line tools, the Figma kit and Claude drafting work now. Intake, DAM, scheduler and single sign-on integrations are designed but not built.
