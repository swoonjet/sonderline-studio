# Sonderline Social System

A prototype AI-assisted production system for **social media content**, built for the SketchDeck *Director of AI Solutions* practical exercise. Sonderline is a fictional brand supplied by SketchDeck.

**AI makes the choices. Code places the pixels. People approve.**

- System overview: `docs/` (coming)

| Path | What |
|---|---|
| `brand-kit/` | Supplied Sonderline kit (logos, Inter Tight OFL, photos, examples). Untouched. |
| `rules/` | Brand tokens + approved copy library (the single source of truth) |
| `engine/` | Spec → HTML → PNG renderer |
| `validator/` | Brand-rule checks on rendered pixels + geometry |
| `studio/` | Web app: brief → spec → renders → checks → export |
| `deliverables/` | Final outputs |
| `review/` | Human-review example (v1 → v2) |
| `docs/` | System overview site |
| `walkthrough/` | Script and recording |

Sources: Inter Tight by Rasmus Andersson (SIL OFL 1.1). Photography is supplied by SketchDeck and is fictional, AI-generated imagery.
